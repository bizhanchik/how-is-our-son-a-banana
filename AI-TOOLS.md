# 🛠️ AI-инструменты, использованные в проекте

Игра **«How Is Our Son A Banana?»** — фруктовая визуальная новелла-теленовелла — собрана
целиком с помощью AI-стека. Ниже — какие инструменты использовались и **как именно** в этом проекте.

## Краткая сводка

| Инструмент | Тип | Для чего использовался |
|---|---|---|
| **Claude Code** | AI-агент (CLI) | Весь код, сценарий, оркестрация остальных тулов, тестирование, деплой |
| **Higgsfield** | MCP / CLI (Seedance 2.0 Fast) | Анимация ключевых сцен (image-to-video) |
| **ElevenLabs (11 Labs)** | MCP / CLI / API | Озвучка всех реплик (5 голосов) + SFX |
| **imggen** *(самописный)* | CLI (OpenAI gpt-image-2) | Все фоны и спрайты персонажей |
| **Context7** | MCP | Актуальная документация фреймворков |
| **Chrome DevTools + Playwright** | MCP | Браузерная автоматизация и E2E-тесты |
| **Кастомные skills для Claude** | `.claude/skills/` | Стандарты разработки, дизайна, QA |

---

## 1. Claude Code (Anthropic)
Основной агент. Написал весь продакшн-код — движок визуальной новеллы на **Next.js 16 + React 19 +
TypeScript + Tailwind v4 + Framer Motion**, state-машину (`useReducer`), все компоненты, сценарий
(нарратор в стиле true-crime, диалоги, твисты), систему скрытого «счётчика подозрения», мини-игру,
три концовки. Оркестрировал все остальные инструменты, прогонял тесты и деплоил на Vercel.

## 2. Higgsfield — MCP / CLI (модель Seedance 2.0 Fast)
**Image-to-video**: оживил ключевые сцены, скармливая уже сгенерированные кадры (фон + персонажи)
как первый кадр. Сгенерированы видео-фоны для: утренней кухни (оба персонажа), ривила
клубничного младенца и ривила бананового младенца. Настройки: **Seedance 2.0 Fast · 4s · 16:9 · 720p**.

## 3. ElevenLabs (11 Labs) — MCP / CLI / API
**Полная озвучка** игры: **65 аудиоклипов** на каждую реплику, нарратора и карточки-переходы,
модель `eleven_v3`. Пять отдельных голосов под персонажей:
Strawberrina (Lily), Bananito (Eric), Strawberto (Chris), Narrator (George), Doctor (Daniel).
Также доступен skill для генерации звуковых эффектов (SFX).

## 4. imggen — самописный CLI (OpenAI **gpt-image-2**)
Собственный инструмент командной строки для генерации изображений через **gpt-image-2**
(и gpt-image-1.5 для прозрачности). Сгенерировано **всё визуальное наполнение**:
17 фонов сцен (кухня, офис, больница, экстерьеры и т.д.) и 9 спрайтов персонажей
(на грин-скрине → кеинг в прозрачность), плюс кадры с фруктовыми младенцами.

## 5. Context7 — MCP
Подтягивал **актуальную документацию** фреймворков во время разработки
(Next.js 16 App Router, Tailwind CSS v4, Framer Motion), чтобы не опираться на устаревшие знания.

## 6. Chrome DevTools MCP (+ Playwright MCP)
**Браузерная автоматизация и тестирование.** Через Chrome DevTools MCP прогонялись все пути игры
(все три концовки), проверялись ошибки консоли, отсутствие 404, метрики загрузки (LCP),
мобильная адаптивность (эмуляция 390px) и снимались скриншоты для верификации. Playwright MCP —
часть стека браузерного E2E-тестирования.

## 7. Кастомные skills для Claude
Набор **самописных скиллов** в `.claude/skills/` (геймдев-направления: `graphics`, `audio`,
`ui-ux`, `qa`, `direction` и др.), а также дизайн-скиллы (`gpt-taste` и т.п.), которые задавали
стандарты кода, визуала и QA-процесса для агента.

---

> Итог: **7 AI-инструментов**, скоординированных Claude Code — от генерации арта и видео до
> озвучки, тестов и деплоя. Ни один ассет не нарисован/озвучен вручную; при этом сама игра
> полностью автономна в рантайме (AI не вызывается во время игры).
